# Demo Storyboard

## 0:00–0:30 — Problem
"Payment proves money moved. It does not prove the purchased task was completed correctly."

## 0:30–1:30 — Agent negotiation
Show the agent selecting a provider through the MCP gateway, quote, SLA, and verification policy.

## 1:30–2:30 — Escrow lock
Show escrow creation, funding, and the Soroban transaction.

## 2:30–3:30 — Successful verification
Show MCP execution, evidence submission, verifier result, and on-chain release.

## 3:30–4:30 — Attack/failure
Toggle the provider into malicious mode. Submit an incorrect result. Show verification rejection and refund.

## 4:30–5:00 — Why it matters
Contrast VAEP with ordinary agentic payments: x402/MPP handle payment negotiation/settlement rails, while VAEP adds task-level accountability, escrow, verification, disputes, and provider reputation.
